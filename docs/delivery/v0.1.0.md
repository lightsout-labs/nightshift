## How to try it

In Claude Code:

```
/plugin marketplace add lightsout-labs/nightshift
/plugin install nightshift@lightsout-labs
```

`/plugin` then shows `nightshift` at version 0.1.0. In an empty git
repository with a GitHub remote, run `/nightshift:spec`, answer its
questions, and type `approve`; `design`, `build`, and `release` follow as the
README describes. Installing from the marketplace was tried on the tagged
version in a fresh configuration, and it listed the six skills.

## Known limits

- The criteria marked *(by hand)* in the backlog are verified only by
  building `gridworks`. Those of S13 (`fix`) and S14 (settings) are not yet
  verified, and neither is `release` on a target project.
- This repository has no `.nightshift` file, so `nightshift.py config` fails
  here; its own workflow is followed by hand.
- `main` protection is a local hook; it stops mistakes, not a determined
  bypass, so server-side branch protection stays necessary.
- Requirements R13 to R15 are delivered by other repositories, not by this
  plugin.
